# 추천 구현 스펙 (Recommended Implementation Specs)

현재 프로젝트의 초기 상태와 PRD를 분석하여, 중복되지 않고 의존성을 고려한 5가지 핵심 구현 스펙을 제안합니다.

## 1. 기본 UI 프레임워크 및 레이아웃 (Foundation & UI)
가장 먼저 전체적인 룩앤필을 담당하는 다크 모드 테마와 반응형 레이아웃을 잡아야 합니다.
*   **핵심 내용**: Tailwind CSS 설정 (다크 모드 #0F1115), 헤더/푸터, 반응형 컨테이너, 모바일 우선 디자인 적용.
*   **명령어**:
    ```bash
    /speckit.specify "프로젝트의 전반적인 UI 뼈대를 잡고 싶어. PRD의 6번 항목(UI/UX 디자인 가이드)을 준수해서 Tailwind CSS 기반의 다크 모드(#0F1115 배경, 흰색 텍스트, 초록색 포인트)를 전역으로 설정해줘. 그리고 모든 페이지에 공통으로 적용될 Header(로고 포함)와 Footer가 포함된 반응형 Layout 컴포넌트를 구현해줘."
    ```

## 2. 익명 사용자 식별 시스템 (Identity)
로그인 없이 사용자를 구분하는 로직은 게시글 작성, 좋아요, 내 글 보기의 기반이 되므로 초기에 구현해야 합니다.
*   **핵심 내용**: UUID 생성 유틸리티, LocalStorage/Cookie 저장 및 조회, UserContext(전역 상태) 구현.
*   **명령어**:
    ```bash
    /speckit.specify "로그인 없는 익명 시스템을 위한 사용자 식별 로직을 구현해줘. PRD 3번(인증 및 사용자 식별)에 따라, 브라우저에서 UUID를 생성하고 이를 Cookie 또는 LocalStorage에 영구 저장하여 사용자를 식별하는 기능을 만들어줘. 이 식별자를 앱 전체에서 쉽게 접근할 수 있도록 React Context 또는 Hook으로 제공해줘."
    ```

## 3. 게시글 관리 시스템 (Post Core)
커뮤니티의 핵심인 글쓰기, 목록 보기, 상세 보기 기능을 구현합니다.
*   **핵심 내용**: 게시글 DB 스키마(Prisma 등 권장), 게시글 작성(유효성 검사, 욕설 필터링), 게시글 목록(최신순), 상세 페이지 구현.
*   **명령어**:
    ```bash
    /speckit.specify "익명 게시글 게시판의 핵심 기능을 구현하고 싶어. PRD 4.1, 4.2, 4.3을 참고해서 게시글(제목, 내용, 카테고리)을 저장할 데이터베이스 스키마를 설계하고, 게시글 작성(욕설 필터링 포함), 최신순 목록 조회, 상세 내용 보기 기능을 수행하는 API와 프론트엔드 페이지를 모두 구현해줘."
    ```

## 4. 인터랙션 시스템 (Comments & Likes)
게시글에 대한 반응을 남기는 댓글과 좋아요 기능을 추가합니다. 이는 게시글 시스템과 사용자 식별 시스템에 의존합니다.
*   **핵심 내용**: 댓글/좋아요 DB 스키마, 댓글 작성/삭제(1단 댓글), 좋아요 토글(중복 방지), 실시간 낙관적 업데이트(Optimistic UI) 고려.
*   **명령어**:
    ```bash
    /speckit.specify "게시글에 대한 소통 기능을 추가해줘. PRD 4.4, 4.5를 바탕으로 댓글(1단 구조) 작성/삭제 기능과 게시글 및 댓글에 대한 좋아요(중복 방지) 기능을 구현해줘. 앞서 만든 익명 식별자를 기준으로 본인 확인 및 중복 체크가 이루어져야 해."
    ```

## 5. 탐색 및 개인화 (Search & My Activity)
사용자 편의성을 높이는 검색 기능과 자신이 쓴 글을 모아보는 기능을 구현합니다.
*   **핵심 내용**: 검색 API (제목+내용), 검색바 UI, 내 글 보기/내 댓글 보기 페이지 (UUID 기반 필터링).
*   **명령어**:
    ```bash
    /speckit.specify "사용자가 콘텐츠를 쉽게 찾고 관리할 수 있는 기능을 구현해줘. PRD 4.6, 4.7에 따라 제목과 내용을 대상으로 하는 게시글 검색 기능과, 현재 사용자의 브라우저 식별자를 기준으로 '내가 쓴 글'과 '내가 쓴 댓글'을 모아볼 수 있는 '내 활동' 페이지를 만들어줘."
    ```
